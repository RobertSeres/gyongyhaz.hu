## 2025-05-14 - Structural Landmark Pattern
**Learning:** Pairing a "Skip to Content" link with a <main> landmark that has tabindex="-1" and focus:outline-none ensures that keyboard users can bypass repetitive navigation and jump directly to the primary content, with focus correctly managed for screen readers.
**Action:** Always implement the "Skip to Content" link as the first focusable element and use a <main> landmark for the primary content area.
