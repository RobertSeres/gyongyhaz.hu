## 2026-07-17 - Structural Landmark Pattern for Keyboard Accessibility
**Learning:** Keyboard-only users need a fast and reliable way to bypass repetitive navigation blocks. Pairing a 'Skip to Content' link as the very first interactive child of `<body>` with a `<main>` landmark element that has `tabindex="-1"` and `class="focus:outline-none"` ensures that focus transitions seamlessly to the core content area without generating an ugly focus ring or disrupting the visual layout for sighted users.
**Action:** In all monolithic static landing pages, implement the 'Ugrás a tartalomra' (Skip to Content) link with `sr-only focus:not-sr-only focus:fixed` classes, targeting a `<main id="main-content" tabindex="-1">` landmark wrapping the primary content. Maintain `<main>` and `<footer>` as sibling elements to preserve correct screen reader HTML semantics.
