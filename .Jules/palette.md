# Palette's Journal - Gyöngy Ház

This journal documents critical UX and accessibility learnings for the Gyöngy Ház project.

## 2025-05-14 - Structural Foundation
**Learning:** Legacy monolithic HTML files often lack basic accessibility landmarks like `<main>` and "Skip to Content" links, which are the highest-impact improvements for keyboard and screen reader users.
**Action:** Prioritize adding `<main>` and skip links before fine-grained component fixes in similar projects.
