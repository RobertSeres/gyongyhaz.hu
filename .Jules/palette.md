# Palette's UX & Accessibility Journal

## 2025-05-14 - Structural Landmark & Skip to Content Pattern in Single Page Beauty Salon App
**Learning:** In a content-dense single-page marketing landing page with fixed navigation and layered z-index modals, keyboard and screen reader users must tab through multiple header navigation anchors before reaching the hero or core services. Implementing a 'Skip to Content' link paired with a `<main id="main-content" tabindex="-1" class="focus:outline-none">` structural landmark provides WCAG 2.1 SC 2.4.1 (Bypass Blocks) compliance. When styling the skip link, high z-index (`z-[150]`) and `focus:fixed` positioning are required so that the element floats over fixed navigation (`z-50`) without breaking page layout. Furthermore, `text-dark-bg` (#0f0f0f) on `bg-pastel-purple` (#C4A7E7) ensures sufficient contrast (>4.5:1), unlike pairing pastel-purple with white text.
**Action:** When working on monolithic or single-page landing pages with fixed headers, always implement the skip-to-content mechanism at the very top of `<body>` targeting a focusable `<main>` element with `tabindex="-1"` and `focus:outline-none` so programmatic focus shift does not produce an awkward permanent focus outline.
