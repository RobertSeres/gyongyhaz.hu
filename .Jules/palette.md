## 2025-05-14 - Structural Accessibility
**Learning:** In legacy monolithic HTML projects, structural navigation improvements (specifically adding `<main>` landmarks and 'Skip to Content' links) provide the highest immediate value for keyboard and screen reader users with minimal code churn.
**Action:** Always prioritize these landmarks and bypass links when auditing a single-page HTML application.
