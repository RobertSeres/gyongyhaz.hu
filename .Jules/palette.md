## 2026-07-25 - Footer Social Media Accessibility and External Anchor Security
**Learning:** Icon-only external links in the footer, such as those targeting Facebook or Instagram, are completely inaccessible to screen reader users unless they are explicitly annotated with descriptive labels in the native language (Hungarian: `aria-label`). Additionally, opening external URLs in a new tab (`target="_blank"`) without specifying `rel="noopener noreferrer"` introduces security risks and performance issues. Finally, placeholder social links using `href="#"` should not include `target="_blank"`, as it creates unnecessary empty tabs and degrades user experience.
**Action:** Always add descriptive, locale-specific `aria-label` attributes to icon-only links. Ensure all external links with `target="_blank"` are decorated with `rel="noopener noreferrer"`. Remove redundant or harmful `target="_blank"` on placeholder or self-referential links.
