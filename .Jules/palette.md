## 2024-05-25 - Accessibility Foundations in Monolithic HTML
**Learning:** In legacy monolithic HTML projects, structural improvements like adding <main> landmarks and 'Skip to Content' links are the highest priority. They provide significant immediate value for keyboard and screen reader users with minimal code churn.
**Action:** Always prioritize the addition of a <main> landmark and a 'Skip to Content' link as the first step in an accessibility audit for single-page applications.

## 2024-05-25 - Interactive Feedback for Client-Side Forms
**Learning:** For forms with purely client-side simulation (like a newsletter signup in a static site), providing immediate visual feedback through loading states (spinners) and success messages is crucial for a "Good UX" feel.
**Action:** Use existing Tailwind animation utilities and Font Awesome icons to implement loading and success states for any form submission.
