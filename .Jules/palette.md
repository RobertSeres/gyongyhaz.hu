## 2025-05-18 - Structural Landmark Pattern & Skip Link Focus Management
**Learning:** In single-page landing sites with fixed navigation bars (`z-50`) and modals (`z-[100]`), keyboard users must tab through repeated header navigation items on every page visit unless a skip link is present. Implementing a skip link requires `z-[150]` and `focus:fixed` so that it renders visibly above all overlays when focused. Additionally, pairing the skip link with a `<main>` container having `tabindex="-1"` and `class="focus:outline-none"` ensures that activating the skip link programmatically shifts focus cleanly to the primary content landmark without an undesirable persistent focus ring.
**Action:** Always place the skip-to-content link as the first child of `<body>` with a z-index exceeding navigation bars and modal overlays, and target a `<main id="main-content" tabindex="-1">` landmark to guarantee WCAG 2.4.1 compliance and seamless keyboard focus flow.
