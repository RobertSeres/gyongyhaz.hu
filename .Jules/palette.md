## 2025-01-24 - Skip to Content & Main Landmark Pattern
**Learning:** In legacy monolithic HTML projects with fixed navigation, adding a `<main>` landmark and a 'Skip to Content' link is the highest-impact accessibility improvement. It significantly reduces repetitive tabbing for keyboard users and provides high immediate value with minimal code churn.
**Action:** Always prioritize adding these structural landmarks in similar static single-page layouts before fine-tuning smaller elements.
