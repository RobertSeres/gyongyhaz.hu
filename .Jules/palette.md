## 2026-01-07 - Structural Landmark and Dialog Patterns
**Learning:** In legacy monolithic HTML projects, adding a `<main>` landmark and a paired "Skip to Content" link provides the highest immediate accessibility ROI for keyboard and screen reader users with minimal code churn. Furthermore, decorative icons within interactive elements should always be explicitly hidden (`aria-hidden="true"`) to prevent screen readers from announcing redundant or confusing characters.
**Action:** Always implement the 'Skip to Content' link as the very first interactive element in `<body>` and ensure it targets a `<main>` element with `tabindex="-1"` to correctly shift focus. For modals, pair `role="dialog"` with `aria-modal="true"` and an appropriate labeling strategy (`aria-labelledby` or `aria-label`).
