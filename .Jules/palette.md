## 2025-05-15 - Structural Accessibility in Monolithic HTML
**Learning:** In legacy monolithic HTML projects, structural navigation improvements (specifically adding `<main>` landmarks and 'Skip to Content' links) provide the highest immediate value for keyboard and screen reader users with minimal code churn compared to fine-grained component fixes.
**Action:** Prioritize adding a 'Skip to Content' link and `<main>` landmark as the first step when auditing monolithic static sites for accessibility.
