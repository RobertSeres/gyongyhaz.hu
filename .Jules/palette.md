## 2026-08-28 - Gallery Image Accessibility
**Learning:** Gallery grid images lacked `alt` attributes, leaving screen reader users without context for visual portfolio showcases of salon services.
**Action:** Always ensure gallery grid `<img>` tags have descriptive Hungarian `alt` attributes matching the service category (hair, nails, cosmetics, massage) to satisfy WCAG 2.1 SC 1.1.1.
