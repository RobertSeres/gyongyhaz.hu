## 2025-05-14 - Structural Landmark Pattern in Monolithic HTML
**Learning:** In legacy monolithic HTML projects with fixed navigation, adding a 'Skip to Content' link paired with a `<main>` landmark is the highest-impact accessibility win. It drastically reduces repetitive tabbing for keyboard users and provides immediate structural clarity for screen readers with minimal code churn.
**Action:** Always check for `<main>` and skip links first in single-page static sites; they form the foundation of a navigable UI.
