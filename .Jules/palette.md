## 2026-07-15 - Structural Landmark Pattern
**Learning:** Pairing a 'Skip to Content' link with a `<main>` landmark that has `tabindex="-1"` and `focus:outline-none` ensures that keyboard users can bypass repetitive navigation while maintaining a clean UI without persistent focus rings on the main container.
**Action:** Always implement this pattern as a foundational accessibility win in monolithic landing pages.
